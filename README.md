# Блог с нуля

<img src="assets/icon.png" width="96" alt="Блог с нуля">

Бесплатный плагин студии разработки **INMI Digital**, основатель — **midi**.
Методики и сопровождение запуска — команда [midi.film](https://instagram.com/midi.film) · [Telegram](https://t.me/midifilm).

**Направление → Темы → Сценарии → Воронка → Продажи**

54 навыка для запуска и развития блога: исследование аудитории, позиционирование, сценарии, съёмка, дизайн, аналитика и автоматизация. Встроенных покупок и платежей нет. Для некоммерческого блога цель адаптируется.

## Скачать и начать

**[Открыть последний релиз](https://github.com/imMeeto/blog-creator/releases/latest)**

- [Нативный плагин ZIP](https://github.com/imMeeto/blog-creator/releases/latest/download/blog-creator.zip) — для поддерживаемой установки в ChatGPT, Claude и Codex.
- [Полный комплект ZIP](https://github.com/imMeeto/blog-creator/releases/latest/download/blog-from-zero-kit.zip) — плагин, руководство и инструкция.
- [START-BLOG.md](https://github.com/imMeeto/blog-creator/releases/latest/download/START-BLOG.md) — для работы прямо в чате.
- [Инструкция установки](INSTALL.md).

При установке используйте **blog-creator.zip**; общий kit — пакет для передачи человеку, а не архив одного плагина. Старый адрес blog-from-zero.zip сохраняется для ранее разосланных ссылок.

## ChatGPT

Карточка в публичном каталоге **ещё не опубликована**. GitHub-релиз не заменяет проверку и публикацию OpenAI.

Если ваш ChatGPT поддерживает установку пользовательского ZIP, загрузите нативный архив штатным способом и завершите шаги Install/сканирования. Если такой возможности нет, приложите START-BLOG.md к чату и напишите:

> Помоги мне начать блог. Начни с вопросов.

Это работа в текущем чате по руководству. Не обещаем, что простое прикрепление ZIP автоматически установит плагин на любом аккаунте.
[Официальная инструкция ChatGPT](https://help.openai.com/ru-ru/articles/20001256-plugins-in-chatgpt).

## Claude

Откройте Customize → Plugins и используйте доступный пункт загрузки собственного ZIP.
Либо добавьте marketplace из **imMeeto/blog-creator** и выберите **blog-from-zero**.
Доступность зависит от плана и настроек организации.
[Официальная инструкция Claude](https://support.claude.com/en/articles/13837440-use-plugins-in-claude).

Для Claude Code:

```text
/plugin marketplace add imMeeto/blog-creator
/plugin install blog-from-zero@blog-creator
```

## Что произойдёт при старте

Плагин коротко представится от команды midi.film, предложит ответить голосом или текстом и начнёт с нескольких вопросов. Если задача уже задана или есть паспорт проекта, продолжит работу по ним.

При запуске из распознаваемого архива плагин инициирует штатную установку, **если** среда действительно умеет открыть пакет и имеет инструмент установки. Обязательные подтверждения платформы остаются в её UI. Уже установленный плагин не дублируется.

## Возможности и ограничения

- Исходные 15 этапов запуска блога и 45 встроенных навыков [midi-skills](https://github.com/imMeeto/midi-skills).
- Сценарии и раскадровки учитывают имеющиеся устройства, реквизит и локации.
- Сходство лица ориентируется на исходные фото; кадры генерируются согласованными пакетами.
- Экраны с точным текстом готовятся вёрсткой; недоступные инструменты не имитируются.
- Самостоятельный START-BLOG.md содержит основной маршрут. Для расширенной библиотеки среде нужны соответствующие файлы полного пакета.
- Плагин не подключает автоматически социальные аккаунты, платежи или публикацию и не гарантирует охваты или продажи.
- Доступность во всех странах, которые поддерживает выбранная платформа; ограничения самой платформы сохраняются.

## Для разработчика

```text
python -m pip install -r requirements-dev.txt
python scripts/build_release.py
python -m unittest discover -s tests -v
claude plugin validate . --strict
```

Готовые файлы создаются в dist/. Пакеты не включают .git, виртуальные окружения, marketplace-каталог и локальные отчёты аккаунта.
