# Установка «Блог с нуля» 1.4.0

Издатель: **INMI Digital**, основатель — **midi**. Команда: [midi.film](https://instagram.com/midi.film), [Telegram](https://t.me/midifilm).
Плагин бесплатный, без встроенных покупок. Версия 1.4.0 содержит 55 навыков, включая reels-storyboard-method; переносимое руководство включает методику «Текст | Кадр» и все шесть рабочих разделов глобального гайда продюсирования.

## Самый короткий путь

[Откройте последний релиз](https://github.com/imMeeto/blog-creator/releases/latest).

1. Если платформа поддерживает пользовательские плагины, скачайте **blog-creator.zip** и используйте штатную установку.
2. Если установки нет — скачайте **START-BLOG.md**, прикрепите к чату и напишите: «Помоги мне начать блог. Начни с вопросов».
3. Ответьте голосом или текстом, если соответствующий ввод поддерживается.

Архив **blog-from-zero-kit.zip** — комплект для передачи: сначала распакуйте его и выберите нативный ZIP внутри. Файл **SHA256SUMS.txt** в релизе содержит SHA-256 загрузок; проверяйте сумму скачанного файла перед установкой.

## ChatGPT

Следуйте [официальным возможностям своего аккаунта](https://help.openai.com/ru-ru/articles/20001256-plugins-in-chatgpt). Установка ZIP/доступ по карточке зависят от плана, роли, поверхности и организации.
Публичная карточка ChatGPT пока не опубликована. Не используйте частную ссылку владельца как универсальный установщик.

## Claude

Customize → Plugins → доступная загрузка своего ZIP. Или Add marketplace → **imMeeto/blog-creator** → Install/Add для **blog-from-zero**.
В Claude Code:

```text
/plugin marketplace add imMeeto/blog-creator
/plugin install blog-from-zero@blog-creator
```

[Справка Claude](https://support.claude.com/en/articles/13837440-use-plugins-in-claude).

## Запуск из архива в чате

Отдельная команда «установи» не требуется, если вы прислали архив для запуска. Однако модель должна иметь доступ к содержимому, а платформа — реальный установщик. ZIP не является автоматически исполняемой программой.
Если архив нельзя прочитать или установить, приложите START-BLOG.md. Плагин честно различает установленный режим и работу по руководству в сессии.

## Продолжение и расширенные функции

Агент сам подбирает навыки, проверяет источники при доступном интернете и предлагает следующий шаг. При старте показывает короткую карту пути; отвечайте обычным текстом или доступным голосовым вводом. Повторный бриф не нужен, если ответы уже есть в чате или паспорте.

Перенесите blog-passport.md / blog-state.json при смене чата. Для полной cp-библиотеки предоставьте среде распакованный пакет либо установите плагин. Один START-BLOG.md не подключает отсутствующие файлы и внешние инструменты.

Не передавайте пароли или API-ключи. Установка не является автоматическим подключением аккаунтов или платежей.
