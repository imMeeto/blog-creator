# Контекст 06 · Дизайн, шрифты, рендер

Всё, что касается визуала: кириллическая типографика, читаемость, размеры, конвейер HTML → PNG, ограничения генеративных картинок.

---

## 1. Шрифты с кириллицей — главный вопрос

**Наличие кириллицы не равно качеству кириллицы.** Большинство популярных шрифтов Google Fonts имеют кириллический набор, сделанный формально.

**ВНИМАНИЕ. Статус этого раздела — уровень C с высоким доверием к источнику, а не уровень A.** Таблица ниже — обоснованное мнение профильного издания словолитни, специализирующейся на кириллице; первоисточник найден и подтверждён, авторы известны и профессиональны. Но это **экспертное мнение одной институции, а не измеряемый стандарт**: критериев с числами здесь нет, и авторы разбора сами являются проектировщиками части шрифтов из положительной колонки. Использовать как сильный аргумент — да; выдавать за объективный норматив — нет.

Профильный разбор нео-гротесков:

| Шрифт | Вердикт | Использовать |
|---|---|---|
| **Golos Text** | «функциональная гарнитура, хорошо подходит для чтения с экрана» | **да** |
| **IBM Plex Sans** (кириллица делалась отдельным дизайнером) | «высококачественная гарнитура, широкий диапазон применения» | **да** |
| Nunito | достаточное качество с неточностями | с осторожностью |
| Inter | кириллице «не хватает внимания к деталям», «использовать не следует» | **не рекомендуется** |
| Manrope | «неубедительна концептуально и плохо реализована» | **нет** |
| Roboto | кириллица «сомнительна», «мало пригодна к применению» | **нет** |
| Oswald | «слишком много проблем, чтобы игнорировать» | **нет** |
| Arimo | «не тот случай, если нужна кириллица» | **нет** |
| Overpass, Alumni Sans | «использовать нельзя» | **нет** |

Это ломает дефолты почти всех открытых скиллов по дизайну — там повсеместно Inter. **Для русского контента Inter не рекомендуется: по умолчанию ставим Golos Text или IBM Plex Sans.** Формулировка именно такая, а не «Inter запрещён»: если Inter уже зафиксирован в брендбуке клиента, это **осознанный компромисс, а не ошибка** — сказать про качество кириллического набора, предложить замену и принять решение клиента, а не переверстывать бренд задним числом.

**Рекомендуемый стек пака (все SIL Open Font License 1.1, бандлятся локально):**

| Роль | Шрифт | Примечание |
|---|---|---|
| Заголовки | **Golos Text** (или Sofia Sans для более выраженного характера) | Golos разрабатывался с кириллицей как первичной |
| Текст | **Golos Text** или **IBM Plex Sans** | |
| Моно, метаданные, код | **IBM Plex Mono** | |

Другие проверенные OFL-шрифты с кириллицей: Fira Sans, Montserrat, EB Garamond, Sofia Sans, Caveat, Shantell Sans, Arsenal, PT Sans / PT Serif / PT Mono.

**ВНИМАНИЕ. Лицензии проверять перед коммерческим использованием.** Многие «бесплатные» шрифты запрещены к коммерческому применению, и тип лицензии различается (desktop / web / app / broadcast). Это самая частая незамеченная утечка прав в макетах.

## 2. Читаемость

**Контраст — WCAG 2.2, уровень A источника:**

| Требование | Значение |
|---|---|
| Обычный текст, AA | **4,5 : 1** |
| Крупный текст, AA | **3 : 1** |
| Любой текст, AAA | **7 : 1** |
| Что считается крупным | ≥18 pt (≈24 CSS px) или ≥14 pt bold (≈18,5 CSS px) |

Обоснование порогов в самом документе: 4,5:1 покрывает пользователей с остротой зрения примерно 20/40, 7:1 — примерно 20/80.

**Кегли на мобильном.** Официального норматива минимального кегля **нет** — ни у Material Design, ни у Apple HIG. Всё, что находится в блогах, без исследовательской базы.

Что можно сказать честно — это арифметика, а не исследование. Карточка 1080×1350 в ленте на экране шириной около 390 CSS px масштабируется примерно **1 : 2,77**:

| Кегль на макете | На экране | Оценка |
|---|---|---|
| 44 px | ≈16 CSS px | нижняя граница нормального чтения |
| 66 px | ≈24 CSS px | попадает в определение «крупного» по WCAG, разрешён контраст 3:1 |
| 90+ px | ≈32+ CSS px | заголовок |

Так и формулировать в выдаче: это пересчёт от размера экрана, а не цитата исследования.

**Объём текста на слайд:** максимум **15 слов**. Правило дистилляции: 3 шага — 3 блока, 10 советов — 10 блоков. Не переносить текст поста целиком.

**Безопасные поля вертикального кадра 1080×1920.** Единственная формулировка, разных чисел по площадкам не приводить:

> Подтверждено только для ВК: отступы **200 px** сверху и снизу (уровень C, вторичный источник). У остальных площадок официальных чисел нет — зона проверяется тестовым кадром на реальном устройстве. Субтитры — не ниже **20% высоты от низа** (уровень C, ремесленная практика).

Число ВК **не распространяется** на другие площадки: ни на сторис Instagram, ни на Shorts, ни на Клипы, ни на Дзен Ролики. Переносить его туда как норму нельзя — там зона проверяется тестовым кадром.

К безопасной зоне не относится и с ней не смешивается: сетка профиля Instagram обрезает карточку до центральных ~1012×1350 (это кадрирование превью, не поле кадра), минимальный внутренний отступ вёрстки — 40 px при холсте 1080–1200.

## 3. Правила слайда

Свод из проверенных открытых наборов, применимых к слайду 1080×1350:

- **Один акцентный цвет.** Не два, не «градиент бренда».
- **Шкала кеглей:** герой 240–300 · h1 96–120 · h2 66–80 · body 52–60 · small 42–44 · служебное 32. Отношение соседних ступеней — **не меньше 1,15**. В рабочем шаблоне `.small` пересчитывается так, чтобы отношение к `.body` было не меньше 1,15.
- **Только пресетные палитры.** Произвольный hex, выбранный моделью, — главный источник «ИИ-вида». Палитра задаётся один раз в теме и не меняется от слайда к слайду.
- **Тема = один файл токенов.** Смена темы — смена одного файла, а не правка каждого слайда.
- Прямые углы и плоские заливки для строгих тем; градиенты, тени и скругления — только если это осознанное решение темы, а не украшение по умолчанию.
- Выравнивание по сетке обязательно.
- Все изображения одной группы — **одинаковой высоты**, иначе ряд разъезжается.
- Двойное ограничение размера текста (по ширине и по высоте), иначе длинная кириллическая строка вылезает за кадр — кириллица шире латиницы при том же кегле.

**Признаки «ИИ-вида», которые режутся при вычитке:** фиолетово-синие светящиеся градиенты; ряд из трёх одинаковых карточек; иконки-эмодзи вместо смысловых элементов; центрированный текст везде; тень под каждым блоком; шрифт Inter в кириллическом тексте, выбранный по умолчанию (а не потому, что он задан брендбуком).

## 4. Конвейер HTML → PNG

Единственный надёжный способ получить корректную кириллицу на картинке.

**Стек:** HTML/CSS → headless Chrome (Puppeteer или Playwright) → PNG. В браузере — `html-to-image` плюс `jsPDF`.

**Правило WYSIWYG:** превью и экспорт идут через **одну и ту же функцию оборачивания слайда**. Две разные функции гарантированно разъезжаются.

**Подводные камни со шрифтами в headless-окружении:**

1. **В контейнере нет шрифтов вообще.** Ставить пакеты шрифтов: базовый набор Noto (покрывает кириллицу), цветные эмодзи, Liberation, плюс сам `fontconfig`.
2. **Забыть обновить кеш шрифтов после установки** — самая частая причина «шрифт поставил, а не видно».
3. **Не поставить `fontconfig`** отдельно от шрифтов.
4. **Права на кастомные шрифты** — файл должен быть читаем процессу браузера.
5. **Эмодзи** без пакета цветных эмодзи рендерятся квадратами.
6. **Не дождаться загрузки шрифтов перед скриншотом** — получится кадр с системным фолбэком, где кириллица выглядит иначе. Ждать готовности шрифтов документа обязательно.
7. **Не грузить шрифты с CDN в момент рендера.** В headless-окружении это гонка и молчаливый фолбэк. Класть локально и подключать через `@font-face` с локальным путём.
8. Рендер в headless может отличаться от обычного режима — проверять на реальном кадре, а не на глаз.

Проверка после сборки окружения: вывести список установленных шрифтов и убедиться, что нужный присутствует.

## 5. Генеративные картинки: где граница

**Кириллица в генераторах в 2026 всё ещё ломается — но не полностью.**

Что известно: модели уверенно работают с **короткими фразами заглавными буквами крупным кеглем**; ломаются на длинных предложениях, мелких подписях и сложной типографике. Английский стабильнее русского — обучение преимущественно на англоязычных данных, русские слова визуально длиннее и шире, буквы похожи друг на друга. Ведущие модели по качеству текста на картинке заявляют многоязычность, но кириллицу отдельно **не гарантируют**.

**Развилка, обязательная к соблюдению:**

| Задача | Путь |
|---|---|
| Текст на слайде, любой длины | **только HTML/CSS → PNG.** Генерация текста кириллицей неприемлема для продакшена |
| Фон, фактура, иллюстрация, атмосферная сцена **без букв** | генерация |
| Одно короткое заглавное слово на обложке | генерация допустима **с обязательной ручной проверкой** |
| «Дизайнерская» картинка с корректным текстом | **гибрид:** сгенерировать фон → наложить текст в HTML → отрендерить |

**Когда вообще код, а когда генерация:**
- нумерованные шаги, фреймворки, сравнения, таблицы, данные → **код**;
- пересказ процесса, метафора, настроение, сцена → **генерация**.

## 6. Форматы и размеры

| Назначение | Размер | Соотношение |
|---|---|---|
| Пост и карусель Instagram | 1080×1350 | 4:5 |
| Слайд под сетку профиля | важное в центральных ~1012×1350 | 3:4 |
| Сторис, вертикальное видео | 1080×1920 | 9:16 |
| Превью YouTube | 1280×720 | 16:9 |
| Квадрат (VK, универсальные) | 1080×1080 | 1:1 |
| Карточка VK Рекламы | 600×600 | 1:1 |
| Обложка PDF, страница A4 | 1240×1754 при 150 dpi | — |

**Превью YouTube — правила читаемости:** проверять на ширине 320 px (мобильная выдача); 3–5 слов максимум; лицо занимает 30–50% кадра, если лицо вообще есть; два цвета плюс акцент, не больше; текст не наезжает на правый нижний угол — там таймкод.
Оговорка: для Shorts превью почти не имеет значения — подавляющее большинство просмотров приходит из ленты, где превью не показывается.

## 7. Тема бренда

Минимальный работающий контракт темы — **палитра плюс пара шрифтов**:

```
--bg          основной фон
--surface     панели и карточки
--text        основной текст
--text-muted  вторичный текст
--accent      единственный акцент
--accent-dim  акцент для мелких элементов, если основной не проходит по контрасту
--font-head   заголовки
--font-body   текст
```

Правила: акцент один; для мелкого текста акцент проверяется на контраст 4,5:1 отдельно и при необходимости заменяется затемнённым вариантом; фон рабочей области за пределами кадра тоже берётся из палитры, чтобы не путать при превью.

Тема заводится один раз скиллом `cp-design-system` и лежит в профиле бренда (`assets.md`). Все визуальные скиллы читают её оттуда.
