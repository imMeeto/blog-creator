# Карта встроенных возможностей

Все маршруты используют [глобальный гайд](producer-method/00-orchestrator.md): стратегия и старт → 01-positioning; роли/идеи → 02-content-and-ideas; сценарии/проверка → 03-script-workshop; выпуск/обучение → 04-production-and-learning; доход → 05-sales-system. Подробные файлы доступны из гайда и читаются по задаче.

Исходные 54 навыка дополнены специальным навыком reels-storyboard-method для сценариев и раскадровок. Управляющий маршрут — blog-launch; расширения включаются под конкретную задачу.

Навыки сам выбирает и применяет агент по [рабочему циклу](12-agent-loop.md). После результата переходи к ближайшей незавершённой задаче и передавай готовый результат следующему навыку. Показывай пользователю понятную работу, а не меню из 55 команд. Чтение общей инструкции из дочернего навыка не запускает ещё один диспетчер.

| Первый запуск / архив / установка | blog-start |
| Направление, личный бренд, аудитория | blog-unpack, cp-personal-brand, cp-audience |

Файлы навыков находятся в ../skills/<имя>/SKILL.md. Читай только выбранные инструкции и нужные справочники. Сохранённые ограничения конкретного проекта важнее производственных рекомендаций по умолчанию.
