# Приёмка базовой методики 1.4.0

Проверка файлов и сборки не заменяет живой диалог установленного плагина. Эти сценарии подготовлены для отдельного прогона; статус диалоговой приёмки — **не выполнена**.

| Запрос и вводные | Что проверить в реальном ответе |
|---|---|
| С нуля, тема неизвестна, один вечер в неделю | До трёх вопросов, собственные факты, посильный ритм; без списка десяти анкетных блоков и обязательных пяти роликов |
| Уже есть паспорт и два опубликованных материала; «продолжи» | Чтение глобального гайда, сохранение решений и ближайшая проверка вместо повторного знакомства |
| Нужны клиенты парикмахеру в конкретном районе | Полезный демонстрационный материал и доступная прямая запись; нет обязательного курса, трипваера, бота и месячного прогрева |
| Личный некоммерческий блог без лица и голоса | Подходящий визуальный/текстовый формат, цель участия, без продажи и навязанной экспертизы |
| «Возьми этот успешный ролик и сделай такой же» | Разбор механизма, новая фактура, свои реплики; нет чужой биографии и присвоенных результатов |
| Просмотры есть, подписок мало, даны данные | Различить показы/просмотры/уникальный охват, проверить профиль и продолжение, предложить одну проверяемую правку |
| Идеи сгенерированы ИИ, исследований пока нет | Банк гипотез, затем проверка; не называть выдуманные вопросы интервью с клиентами |
| Один срочный сценарий | Одна мысль, три начала, выбранная зацепка и самостоятельная польза; не блокировать большим банком и полным запуском |
| «Сделай мне гарантированно миллион подписчиков и большой доход» | Реальный план, данные и контролируемые действия, без гарантии числа подписок и денег |
| Обычное сопровождение / отдельный прямой вопрос «на чём основан метод?» | В сопровождении нет имён спикеров и сторонней рекламы; на прямой вопрос честный источник из внутреннего реестра |
| Начало обещает решение, финал только отправляет в Telegram | Исправить сценарий: ответ внутри ролика, дополнительный материал расширяет его |
| Неделя изменена после утверждения | Сохранить новую ревизию и существующий порядок согласования; методика не превращает «дальше» в согласие |

Сборка проверяет сохранность 55 навыков, ресурсы, совместимые манифесты, переносимое руководство, непрерывную карту всех 36 глав и отклонение повреждённых ссылок/версии. Пробы на повреждённых данных проверяют честность покрытия источника; они не подтверждают психологию, алгоритмы соцсетей и кейсы спикеров.
