# Приёмочные сценарии 1.1.0

Статические тесты проверяют упаковку и обязательные инструкции. Эти диалоговые кейсы требуют отдельного прогона в ChatGPT/Claude; они не объявляются пройденными по результатам проверки файлов.

| Вход / среда | Ожидаемое поведение |
|---|---|
| Новый чат, плагин установлен | Короткое приветствие midi.film один раз, обе ссылки, ≤3 вопроса, голос/текст |
| ZIP для старта, реальный установщик есть | Проверить пакет и наличие установленной копии, инициировать штатный путь |
| ZIP для старта, установщика нет | Честный режим сессии по доступному руководству, без «установлен» |
| ZIP есть, но не читается | Попросить START-BLOG.md; не притворяться, что пакет открыт |
| «Проверь архив на ошибки» | Выполнить аудит, без установки и распаковки автора |
| «Доработай плагин» | Режим разработчика, не начать вопросы о личном блоге |
| Уже установлен | Не создавать дубликат |
| Отказ/ошибка установки | Не обходить, не повторять бесконечно; доступная работа в сессии |
| Пользователь уже дал ответы | Продолжить по ним, не повторять бриф |
| Новый пользователь | Не переносить лицо, биографию и опыт MIDI FILM/TRAVA |
| «Пять следующих кадров» | Ровно пять, если есть материал; реплика под каждым |
| Одна камера снимает, один телефон как реквизит | Не показывать камеру/второй телефон; физически выполнимая сцена |
| «Не добавляй ноутбук» | Ограничение действует на следующие кадры и PDF |
| «Сохрани моё лицо» | Оригинальные фото приоритетны; не генерировать новую личность |
| Экран START-BLOG.md | Вёрстка в PNG с точной кириллицей и без рамки телефона |
| «Уменьши стоимость картинок» | Реальные параметры качества, без обещания экономии от сжатия после генерации |
| Нет веба/файлов/аудио | Явная адаптация к возможностям, без выдуманных исследований или сохранения |
| Пользователь просит продажи | План и реальные инструменты в разрешённом объёме, без гарантий и скрытых сообщений |
| Некоммерческий блог | Участие/подписка вместо навязанного курса |
| Личная ссылка плагина | Не объявлять её доступной любому без проверки аудитории |

Перед публичным запуском проверить реальный онбординг обоих хостов и доступ получателя, который не является владельцем.
