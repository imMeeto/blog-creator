# Семь каркасов карусели · примеры слайд за слайдом

Каркас — порядок типов слайдов, а не текст. Тексты ниже показывают ритм и плотность, их нельзя копировать в чужой бренд дословно: голос берётся из `voice.md`, боли — из `audience.md`.

**Как читать примеры.** `[…]` — место, куда подставляется факт из `facts.md`. Цифра без источника и даты на слайд не выходит — это не стилистика, это правило пака. Ни один пример ниже не содержит выдуманных чисел намеренно.

**Общее для всех семи:**
- слайд 1 — хук, слайд 2 — самостоятельная обложка со **своим** хуком другого механизма;
- лимит слов по классу слайда: повествовательный — ≤15 слов; список и чек-лист — 3–5 пунктов по ≤6 слов, не больше 30 слов на слайд; сравнение — до 3 пар строк по ≤5 слов. На слайдах 1 и 2 главная строка ≤6 слов;
- предпоследний слайд **оплачивает обещание**, но форма оплаты у каждого каркаса своя: резюме, вывод, урок, порог-условие, итог подборки. Слот один и обязателен, названия типов разные;
- последний — одно действие;
- тексты слайдов перед выдачей проходят `cp-voice` и `cp-humanizer`: примеры ниже показывают плотность, а не готовый голос бренда.

Механизмы хуков в скобках — по `context/04-hooks.md`.

## 1. Обучающая

хук → обложка → тезис → шаг ×3–5 → оплата → CTA

Объясняет метод. Самый безопасный каркас: работает без кейсов и без цифр.

**Ниша: услуги для бизнеса**

| № | Тип | Текст | Визуал |
|---|---|---|---|
| 1 | Хук (1.2 диагностический разрыв) | «Заявки есть. Денег нет» | Крупная строка на фоне, один акцент на слове «денег» |
| 2 | Обложка (4.1 прямая адресация) | «Если считаешь заявки, а не сделки — это тебе» | Другая композиция, текст в нижней трети |
| 3 | Тезис | «Заявка — не результат. Результат — оплата» | Две строки, вторая акцентом |
| 4 | Шаг 1 | «Разбей путь клиента на пять точек» | Номер шага крупно слева |
| 5 | Шаг 2 | «Посчитай, сколько людей проходит каждую» | Тот же макет, меняется только содержание |
| 6 | Шаг 3 | «Найди точку, где теряется больше половины» | |
| 7 | Шаг 4 | «Чини одну точку за раз. Меряй две недели» | |
| 8 | Оплата и резюме | «Пять точек, одна правка, две недели замера» | Резюме всех шагов в столбик мелким кеглем |
| 9 | CTA | «Сохрани — пригодится на планёрке» | Один акцентный блок |

**Перенос в другие ниши.** Ремесло: «Пять точек» → пять этапов заказа. Здоровье: → пять шагов подготовки. Обучение: → пять этапов разбора работы. Скелет не меняется.

## 2. Разбор

хук → обложка → изображение-факт → тезис ×2 → цифра → оплата: вывод → CTA

Вскрывает конкретный пример. Требует своего материала: скриншота, документа, кадра. Чужой материал — только с атрибуцией и собственным комментарием, иначе это попадание под правило оригинальности.

**Ниша: локальный бизнес**

| № | Тип | Текст | Визуал |
|---|---|---|---|
| 1 | Хук (2.2 обратный порядок) | «Разбираю, почему это не сработало» | Затемнённый скриншот фоном, текст поверх |
| 2 | Обложка (5.3 демонстрация) | «Витрина обновлена. Выручка на месте» | Само фото витрины, подпись в углу |
| 3 | Изображение-факт | Подпись: «Как выглядело до и после» | Своё фото, без текста поверх |
| 4 | Тезис | «Меняли оформление. Не меняли повод зайти» | |
| 5 | Тезис | «Красиво — не причина. Причина — задача клиента» | |
| 6 | Цифра | «[показатель] за [период] · источник: [где взято]» | Число во весь слайд, источник мелко снизу |
| 7 | Оплата: вывод | «Сначала повод. Потом оформление» | Итог одной строкой |
| 8 | CTA | «Напиши, что у тебя за повод зайти» | |

**Если подтверждённой цифры нет.** Слайд 6 не остаётся пустым и не смягчается словом «примерно». На его месте — **собственное наблюдение с явной пометкой** («на своей практике вижу так — это наблюдение, а не статистика») или **честная граница** («когда это не работает: [условие]»). Число слайдов не меняется, роль слайда та же — доказательство перед выводом.

**Правило разбора.** Если разбирается чужой пример — не переходить на личности и не выносить внутренние данные, которых нет в публичном доступе. Разбор строится на видимом всем.

## 3. Миф и правда

хук → обложка → сравнение ×3 → цитата-источник → оплата: что делать → CTA

Снимает массовое заблуждение. Самый требовательный к доказательности каркас: каждое «правда» нужно чем-то подтвердить, иначе это не разоблачение мифа, а свой миф вместо чужого.

**Ниша: экспертная практика**

| № | Тип | Текст | Визуал |
|---|---|---|---|
| 1 | Хук (2.1 контрарное утверждение) | «Три правила, которых никто не вводил» | |
| 2 | Обложка (1.4 именованный секрет) | «Это называется отраслевой фольклор» | Другой фон, крупная типографика |
| 3 | Сравнение | Миф: «[формулировка]» / Правда: «[что на самом деле]» | Две колонки, до 3 пар строк, ≤5 слов в строке |
| 4 | Сравнение | тот же макет | Ряд из одинаковых блоков, ничего не съезжает |
| 5 | Сравнение | тот же макет | |
| 6 | Цитата-источник | «[прямая цитата документа или справки] — [источник, дата]» | Кавычки как графический элемент, атрибуция обязательна |
| 7 | Оплата: что делать | «Проверяй в первоисточнике. Ссылка в комментарии» | |
| 8 | CTA | «Какой миф разобрать следующим» | |

**Красная линия каркаса.** Нет источника на «правду» — слайд снимается. Заменять источник фразой «на самом деле» нельзя: это тот же миф, только свой.

**Чем заменить слайд 6, если источника нет.** **Честная граница**: «надёжных публичных данных по этому нет — вот как проверить у себя за [срок]». Оплата на слайде 7 тогда формулируется как способ проверки, а не как вывод. Если источника нет ни на одну из трёх «правд», каркас меняется целиком: бери «Обучающую» и объясняй метод — миф снимается методом, а не своим мифом вместо чужого.

## 4. Чек-лист

хук → обложка → чек-лист ×2–3 слайда → цифра-порог → CTA

Даёт инструмент. Каркас с самой высокой сохраняемостью, потому что к нему возвращаются.

**Ниша: подготовка к чему-либо (сделка, запуск, сдача работы)**

| № | Тип | Текст | Визуал |
|---|---|---|---|
| 1 | Хук (3.2 цена ошибки) | «Одна строка стоит дороже всей работы» | |
| 2 | Обложка (6.1 жёсткая рамка) | «Девять пунктов. Проверка за десять минут» | Число крупно, подзаголовок мелко |
| 3 | Чек-лист 1–3 | Три пункта, по 4–6 слов | Единый макет отметки слева |
| 4 | Чек-лист 4–6 | Три пункта | Тот же макет |
| 5 | Чек-лист 7–9 | Три пункта | Тот же макет |
| 6 | Цифра-порог | «Не сходится хотя бы в трёх — не подписывай» | Условие, а не обещание |
| 7 | CTA | «Сохрани и пройди по списку сегодня» | |

**Как не сломать.** Пункты одного уровня абстракции и одной грамматической формы: все глаголами или все существительными. Смешение форм читается как небрежность сильнее, чем любая опечатка.

## 5. До и после

хук → обложка → до/после ×2–3 → процесс-как → оплата → CTA

Показывает результат, который видно глазом. Требует настоящих материалов и осторожности с обещаниями.

**Ниша: любая, где есть видимый результат работы**

| № | Тип | Текст | Визуал |
|---|---|---|---|
| 1 | Хук (5.3 демонстрация) | Без текста или два слова | Кадр «после» на весь слайд |
| 2 | Обложка (5.2 сжатие «было-стало») | «Тот же объект. Другая задача» | Диптих: половина «до», половина «после» |
| 3 | До/после | «Было: [состояние] · Стало: [состояние]» | Две картинки одинаковой высоты — иначе ряд разъедется |
| 4 | До/после | второй объект | Тот же макет |
| 5 | Процесс-как | «Что изменилось: [три пункта]» | Текстовый слайд, чтобы разгрузить глаз |
| 6 | Оплата и резюме | «Результат — не переделка. Результат — снятая задача» | |
| 7 | CTA | «Покажу разбор ещё одного — напиши слово [триггер]» | |

**Комплаенс каркаса.** «До/после» — зона обещания результата. Формулировать как описание конкретной работы («вот что было и что стало у этого объекта»), а не как обещание («будет так же»). В нишах здоровья, финансов и юридических услуг проверять отдельно: `cp-compliance`.

## 6. История

хук → обложка → тезис-завязка → шаг ×3 → поворот → урок → CTA

Продаёт через опыт. Единственный каркас, где допустима эмоция вместо списка.

**Ниша: личная практика, любой профиль**

| № | Тип | Текст | Визуал |
|---|---|---|---|
| 1 | Хук (4.3 признание) | «Я делал это [срок] и был неправ» | |
| 2 | Обложка (3.2 цена ошибки) | «Ошибка обошлась в [ресурс: срок, а не сумма]» | Другой ракурс, текст иначе выровнен |
| 3 | Тезис-завязка | «Всё выглядело правильно. И не работало» | |
| 4 | Шаг | «Сначала я решил, что дело в [очевидное]» | |
| 5 | Шаг | «Потом — что в [второе очевидное]» | |
| 6 | Шаг | «Дело было в [неочевидное]» | Акцент здесь, а не на слайде 1 |
| 7 | Поворот | «Проверить это можно было за час» | |
| 8 | Урок | «Сначала проверяй дешёвое. Потом дорогое» | Резюме, которое сохраняют |
| 9 | CTA | «Расскажи, на чём обжигался ты» | |

**Почему работает.** Признание и цена ошибки — механизмы 4.3 и 3.2. Требование: история должна быть настоящей. Выдуманный кейс в личном бренде — самая дорогая ошибка репутации, дороже любого просчёта в оформлении.

## 7. Подборка

хук → обложка → список ×N → цифра или цитата → CTA

Инструменты, ошибки, источники, форматы. Легко собирается, легко превращается в конвейер — чередовать с другими каркасами обязательно.

**Ниша: любая**

| № | Тип | Текст | Визуал |
|---|---|---|---|
| 1 | Хук (1.3 счётный разрыв) | «Шесть инструментов. Четвёртый спорный» | Число крупно |
| 2 | Обложка (4.1 прямая адресация) | «Если ты собираешь это руками — забери» | |
| 3–8 | Список, по одному пункту на слайд | «[Название] — [что делает], [ограничение]» | Единый макет: название, строка, ограничение мелко |
| 9 | Цифра или цитата | «Из шести бесплатны [N] · проверено [дата]» | |
| 10 | CTA | «Сохрани список, пока не разъехались ссылки» | |

**Потолок в 10 слайдов здесь не случаен.** Подборка — единственный каркас, который тянет вширь: пунктов всегда хочется больше. Публикация через Graph API режет карусель на **10** слайдов, и одиннадцатый просто не уедет. Поэтому каркас сведён ровно к десяти. Нужно больше пунктов — сначала спроси способ публикации: 20 слайдов доступны только при публикации из приложения Instagram, для API и Telegram (2–10) список дробится на две карусели или сокращается.

**Обязательное для подборок.** У каждого пункта называется ограничение, а не только польза — подборка без ограничений читается как реклама и, если за неё платят, ею и является: тогда маркировка обязательна. Платный инструмент подаётся с пометкой «платно, необязательно».

## Как выбрать каркас за три вопроса

1. **Есть ли свой материал — фото, скриншот, документ?** Есть → «Разбор» или «До/после». Нет → «Обучающая», «Миф/правда», «Подборка».
2. **Что читатель должен унести — понимание или инструмент?** Понимание → «Обучающая», «История», «Миф/правда». Инструмент → «Чек-лист», «Подборка».
3. **Чем подтверждается сказанное?** Источниками → «Миф/правда». Своим опытом → «История». Ничем, кроме логики → «Обучающая», и без цифр.

## Чего в каркасах нет намеренно

- Слайда «привет, меня зовут» — представление не удерживает и съедает второй слайд, самый ценный.
- Слайда «в этой карусели вы узнаете» — оглавление вместо содержания.
- Двух CTA. Второй призыв отменяет первый.
- Плашки «листай дальше» как замены хуку на втором слайде. Стрелка не хук.
